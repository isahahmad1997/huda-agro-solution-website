# Huda Agro-solution Limited — Website

Static portfolio website for Huda Agro-solution Limited, Tarauni LGA, Kano State, Nigeria.

## Included
- `index.html` — responsive homepage
- `assets/` — logo and livestock photos
- `.nojekyll` — ensures GitHub Pages serves all files without Jekyll processing

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository, e.g. `huda-agro-solution-website`.
2. Choose **Public** if you want the website to be publicly accessible without GitHub plan restrictions; leave the repository empty when creating it (no README or license needed).
3. Upload the contents of this package to the repository root. Make sure `index.html`, `.nojekyll`, and the `assets` folder are at the root level; do not upload the containing parent folder.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, set **Deploy from a branch**; select branch `main` and folder `/(root)`, then press **Save**.
6. Wait a few minutes, then return to **Settings → Pages** for the public website address. It will usually look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before sharing
- Open the published address on a phone and computer and test the navigation, WhatsApp, phone and email links.
- The enquiry form prepares a WhatsApp message for the visitor to review and send. This static website does not save enquiries to a database.
- Contact information and brand content can be edited in `index.html`.
